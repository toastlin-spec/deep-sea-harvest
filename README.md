# 深海大豐收

從上方俯視海面的街機風釣魚遊戲。拋竿、控制張力搏魚，用釣到的金幣升級裝備、購買道具，慢慢挑戰深海的 BOSS 魚。

**線上試玩：https://toastlin-spec.github.io/deep-sea-harvest/**

整個遊戲就是一個 HTML 檔，不需要安裝或建置：直接用瀏覽器打開 `index.html` 就能玩。進度會存在瀏覽器的 localStorage。

## 操作

| 按鍵 | 動作 |
|---|---|
| ← → | 瞄準拋竿方向；搏魚時把竿子往魚衝刺的反方向壓，可以卸力 |
| 按住 空白鍵 | 蓄力，放開就拋竿；搏魚時按住捲線 |
| 按一下 空白鍵 | 浮標整個沉下去、出現「！」時揚竿 |
| 1 | 電擊棒：搏魚時讓魚麻痺 3 秒 |
| 2 | 手電筒：照亮海面 25 秒，吸引魚來咬餌 |
| 3 | 漁網：魚拉近到 20 m 內時撒網提早收魚 |
| S / B / H / M | 商店／圖鑑／說明／音效開關 |

也可以用滑鼠點畫面代替空白鍵；觸控裝置會顯示螢幕按鈕。

## 玩法重點

- **張力控制**：張力保持在綠色區，魚的體力才會下降。太高會斷線，太鬆魚會脫鉤。
- **魚跳水**：搏魚時魚偶爾會跳出水面，這時要立刻放開空白鍵。
- **大豐收時間**：每釣到一條魚就會累積豐收量表，集滿後進入 30 秒大豐收，金幣 ×1.5。
- **時段與天氣**：白天、黃昏、夜晚、清晨輪流變化，夜晚有會發光的夜行魚；雨天大魚較多，霧天稀有魚較多。
- **升級**：釣竿、釣線、捲線器、魚餌各 5 級。
- **圖鑑**：12 種魚，包含 2 隻 BOSS（大白鯊、雨傘旗魚）。

## 技術

- 純 HTML + Canvas 2D + 原生 JavaScript，沒有外部函式庫
- 音效用 Web Audio API 即時合成
- 字型來自 Google Fonts（Noto Sans TC、Chakra Petch），離線時會改用系統字型
